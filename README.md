# DeepPipe Mobile for QField — v0.2.0

This repository contains the standalone, touch-first QField implementation of
the DeepPipe workflows. It is independent from the DeepPipe web portal
repository and does not contain the portal frontend or backend.

## Deliverables

- `plugin/deeppipe-mobile/`: app-wide QField plugin source.
- `project-template/`: synthetic demo project configured for the live Prediction API.
- `docs/`: architecture, API contract, project schema, and device test matrix.
- `tests/`: pure JavaScript, source/package, and read-only live-contract checks.
- `dist/deeppipe-mobile-v0.2.0.zip`: installable plugin package.
- `dist/DeepPipe_QField_API_Test_v0.2.0.zip`: optional complete debugging bundle generated by `build.sh` (not tracked).

The main Prediction interaction is:

```text
Open DeepPipe → Select inlets on map → Tap points → Done → Review settings → Submit → Poll job → Result layer
```

There is no inlet-list upload screen. The plugin snapshots selected point features from the configured QField inlet layer, including locally saved observations that have not yet synchronized.

Prediction defaults to `https://lab.yyworkshop.com/predapi`; a mock fallback
remains available in Setup. Assessment is still mock-only in 0.2.0. The live
API currently has no authentication, so this release is for workflow testing
and must not be used to submit sensitive field data.

## Install in QField

Host `dist/deeppipe-mobile-v0.2.0.zip` at a direct public HTTPS URL. Then open
**Settings → Plugins → Install plugin from URL** in QField and enter that URL.
The URL must return the ZIP itself rather than an HTML page or sign-in screen.

For the first device test, open `project-template/DeepPipe_Mobile_Demo.qgs`
and follow `docs/TESTING.md`.

## Build and test

```bash
node tests/test_logic.mjs
node tests/validate_source.mjs
node tests/test_api_contract.mjs
./build.sh
```

The pure-JS, source, demo-project/GeoJSON, live-contract, and ZIP checks do not replace a QField phone test. Follow `docs/TESTING.md` on QField 4.2.10 for Android and iOS.

## Host the installer

Copy `dist/deeppipe-mobile-v0.2.0.zip` to a stable public HTTPS URL on the
deployment server. The URL must return the ZIP bytes directly (not a login or
HTML download page), preferably with `Content-Type: application/zip`. In
QField, open **Settings → Plugins → Install plugin from URL** and enter that
URL. The complete API test bundle generated by `build.sh` is for debugging and
is not the installable plugin.
